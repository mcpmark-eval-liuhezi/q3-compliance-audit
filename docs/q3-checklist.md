# Q3 Vendor-Compliance Audit Checklist

## Vendor access review

- [ ] Confirm each vendor has a current signed access agreement on file
- [ ] Review list of active vendor accounts and flag dormant credentials
- [ ] Verify multi-factor authentication is enforced for all vendor access
- [ ] Remove or rotate credentials for vendors with expired contracts
- [ ] Document approval for any vendor granted elevated privileges

## Dependency version audit

- [ ] Inventory all first-party and third-party dependencies
- [ ] Confirm each dependency is on a supported version
- [ ] Cross-check versions against the approved vendor list
- [ ] Record remediation plans for out-of-date or EOL packages
- [ ] Obtain sign-off from the system owner on the final inventory

## Data retention sign-off

- [ ] Confirm each data category has a documented retention period
- [ ] Verify retention periods align with vendor contract terms
- [ ] Review deletion or archival procedures for expired data
- [ ] Confirm data residency requirements are met for all vendors
- [ ] Obtain final sign-off from the data protection owner
